## Installation
**Requirements:** `nvm`, `node`

1: nvm
```node js
nvm use
```
2: Install Dependencies
```node js
yarn install
```
3: Compile and Run the project
```node js
yarn run start
```

> [!NOTE]
> Package updates and dependency changes may cause some issues when getting the project up and running
